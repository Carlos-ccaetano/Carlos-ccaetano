# Profile tooling

- Edit `content.json` for profile copy, stack, and certifications.
- Edit `tokens.mjs` for the four design colors.
- `npm run build` regenerates the hero, PNG, README, checklist, and previews.
- `npm run check` validates generated content, contrast, assets, and accessibility rules.
- Fonts are vendored in `fonts/`; their OFL licenses are stored beside them.
- Preview renders are local-only under `preview/`.
- Do not commit reference images or original photos.
